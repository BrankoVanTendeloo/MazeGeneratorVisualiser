Maze Generator Visualiser

The maze generator visualised here is called "Origin Shift" and was developed by the YouTube channel MattBatWings. It generates a perfect maze utilising a directional graph. It shifts a so-called "origin point" to dynamically change the maze's layout without making an entirely new maze. It is capable of generating a lot of different perfect maze for the given grid size. The algorithm could be extrapolated to any grid, including hexagonal grids, oddly-shaped grids, or grids of higher dimensions. The main disadvantage of the generator is its lackluster speed.

A perfect maze is any maze that has no loops in its paths. So from any two points in the maze, there is exactly one path between them.

Above, you can use the buttons to see how the maze interacts with origin movement. Use the arrows to manually move the origin point. Use the circle button to move it randomly. Use the big button to start running the algorithm as fast as possible. You can also resize the grid the maze is generated in.
